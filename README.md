# AI Clinic Assistant

AI-powered clinic assistant built with FastAPI and Google Gemini.

## Features

- FastAPI REST API
- Google Gemini
- Arabic responses
- Clinic data stored in JSON

## Tech Stack

- Python
- FastAPI
- Google Gemini
- Pydantic

## Run

```bash
pip install -r requirements.txt
uvicorn app:app --reload
```

Open:

http://127.0.0.1:8000/docs
